Configura a API do Mailton para enviar emails automáticos de aprovação e rejeição de contas.

Como obter a API Key do Mailton

  1. Acede a mailton.co e cria uma conta gratuita
  2. No painel, vai a API Keys → Create new key
  3. Copia a chave gerada e cola no campo abaixo
  4. Em Verified Senders, adiciona e verifica o email remetente
  5. Guarda as configurações — os emails serão enviados automaticamente
